# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
private reporting flow instead:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include the affected version or commit, steps to reproduce, and impact.

Recall runs entirely in the browser and does not send review data to a server.
Vulnerabilities worth reporting include cross-site scripting through imported
backup files, unsafe handling of local storage, and supply-chain issues in the
build or dependencies.

You can expect an initial response within seven days.
